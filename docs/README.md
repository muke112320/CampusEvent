## 运行与复现

```powershell
.\.venv\Scripts\python.exe run.py
.\.venv\Scripts\python.exe -m pytest -v
```

代码对应两个 Git 标签：

- `baseline-v1`：初始验收版本（29 passed）；
- `change-v2`：按教师 CR-01/CR-02 完成的变更版本（41 passed），已部署到 <http://120.76.59.189/campusevent/>。

`baseline-v1` 的源代码保持初版不变；`change-v2` 起文档补充变更内容（`01`、`02`、`03`、`04`、`05`、`07`、`09`），并新增两版对照，便于逐项检查“初版 → 变更版”的差异。`06_设计评审记录表.md` 的签名与班级/学号需由本人/评审同学补充，文档不填写虚构信息。
